如果 DQ-绘图 对你有帮助，欢迎通过[赞助支持页面](/docs/support/donate)扫码支持项目维护、模型测试和文档迭代。

## 致谢

DQ-绘图 基于开源项目持续开发。感谢上游开源贡献者对画布创作工作流、Canvas Agent 和 Codex 插件能力的贡献。

感谢 社区朋友 **Kitty的猫** 对 DQ 的持续赞助与支持，帮助项目继续维护、测试和迭代。

也感谢 Linux DO 社区、相关提示词开源仓库、Codex / Claude Code 生态，以及 React、Next.js、Ant Design、PostgreSQL、FFmpeg、Fumadocs 等项目使用的所有开源工具与基础设施。

## 参与项目

- 给 GitHub 仓库点 Star，帮助更多人看到项目。
- 使用脱敏信息提交可复现的 Issue。
- 补充文档、测试、模型渠道适配或小范围修复。
- 提交代码前阅读仓库根目录的 `CONTRIBUTING.md`、`AGENTS.md` 和 `CLA.md`。
