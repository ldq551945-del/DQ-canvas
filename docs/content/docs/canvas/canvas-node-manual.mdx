# 画布节点操作手册

本文档记录当前画布节点、生成任务和图片工具的主要用途。真实模型、计费、失败退款和跨实例恢复仍以[待测试](/docs/progress/pending-test)中的生产验收结果为准。

## 创建与组织节点

“添加组件”菜单提供七类入口：文本、图片、全景图、绘图、视频、音频和生成配置。双击画布空白处也可打开同一菜单，方向键、`Home`、`End`、`Enter` 和 `Esc` 可完成键盘选择。

- 图片、视频和音频可以从本地上传、粘贴或从“我的素材”插入。
- 多选两个以上节点后可编组；拖动任一已选组成员时，同组节点一起移动。解除编组不会删除节点或连线。
- 图片节点的锁定只冻结位置和尺寸，内容、提示词、参数和图片工具仍可编辑；锁定状态参与撤销和项目持久化。
- 媒体“替换”会保留节点 ID、中心点和现有连线，并按新媒体的自然尺寸更新预览。
- `auto / quality / performance` 性能模式控制复杂画布的重绘成本；自动模式在节点达到 80 个或媒体节点达到 32 个时采用性能策略。

## 连接、引用与任务

- 从节点两侧胶囊端口拖动可创建连线，端口会记录垂直锚点比例。
- 悬停或选中连线时，中点会显示 `+` 插入柄。拖到空白处后选择新组件，会把原连线拆成“来源 -> 新节点 -> 目标”；拖到兼容节点则直接接入该节点。
- 节点输入中的连接素材显示为可读 token；稳定引用使用 `@[node:节点ID]`，Skill 使用 `@[skill:SkillID]`。提交时服务端再校验引用、归属和真实素材。
- 视频输入支持 Skill、首帧和尾帧选择，发送顺序由结构化引用保存，不依赖界面显示文本反向解析。
- 任务面板显示服务端返回的真实阶段、进度、耗时和计费状态。未知百分比使用不确定进度，不伪造剩余时间。
- 每次主动提交使用新的 submission ID。撤销、删除或替换目标节点后，旧运行令牌失效，迟到结果不会写回已经变化的节点。

## 文本节点

文本节点用于保存提示词、草稿、说明文案和 AI 生成的文字结果。它既可以作为独立文本内容，也可以作为下游生成配置节点的输入。

### 编辑文本内容

- 双击文本节点内容区域，直接编辑节点里的文字。
- 选中文本节点后，点击顶部工具栏的“编辑文字”，进入文字编辑状态。
- 顶部工具栏的“缩小”和“放大”用于调整文本节点字号。

### 用下方对话框生成或修改文本

- 选中文本节点后，点击顶部工具栏的“编辑”，打开节点下方对话框。
- 文本节点下方对话框只用于生成或改写文本，不承担生图功能。
- 当文本节点为空时，输入框用于填写想生成的文本内容；点击发送后，结果会回填到当前文本节点。
- 当文本节点已有内容时，输入框用于填写想把本段文本修改成什么；点击发送后，会在右侧生成新的文本节点，并自动连接原节点和新节点。
- 输入内容可以手写，也可以从提示词库选择。
- 对话框里的模型下拉来自全局配置里已拉取的模型列表；选择结果只作用于当前节点，不会修改其它节点或全局默认模型。
- 如果下拉中没有模型，需要管理员进入后台系统设置拉取模型列表，并设置默认生图模型和默认文本模型。火山方舟 Agent Plan 若提示不支持 `/models`，请在后台手动填写模型名。

### 用文本节点生成图片

- 先在文本节点中准备好要用于生图的文本内容。
- 点击文本节点顶部工具栏的“生图”按钮。
- 系统会在文本节点右侧自动创建一个生成配置节点，并连接文本节点到生成配置节点。
- 生成配置节点会读取上游文本内容作为生图提示词，并立即开始生成图片。
- 后续需要调整模型、比例、数量时，可以在生成配置节点里修改后再次生成。

### 用图片节点继续生成图片

- 选中空图片节点后点击“生成”，会直接在当前节点里生成结果，不再额外保留一个空框。
- 当数量为 `1` 时，生成结果会直接回填到当前图片节点。
- 当数量大于 `1` 时，当前图片节点会作为主图节点，右侧继续生成对应数量的子图节点。
- 如果图片节点本身已经有内容，则会沿用已有图片作为参考图，再生成新的图片批次。
- 每个生成出来的图片节点都会在自身 `metadata` 下记录提示词、生成类型、模型、尺寸、质量、数量和参考图引用，方便后续重试。
- 如果重试时参考图已经丢失或无法恢复，系统会直接提示，避免误发空的图生图请求。

## 图片节点高级工具

| 工具 | 功能与边界 |
| --- | --- |
| 标注 | 在图片上绘制标记并保存为独立派生节点，不覆盖源图 |
| 情绪 | 检测或手动选择人脸，在 5x5 情绪网格中选择方向；可使用 FaceCap 3D 预览，生成时保留源图、人物参考图和蒙版参数 |
| 人物质感 | 从五组三级参数生成结构化人物质感提示，继承源图比例并创建派生结果 |
| 多视角 | 设置水平角度、俯仰、距离和广角参数，源图继续作为参考素材 |
| 锁定 | 只锁定节点几何位置与尺寸，不锁定内容、提示词或生成参数 |
| 快捷工具 | 默认固定 7 项，最多固定 8 项；锁定入口独立显示，不占快捷名额 |

情绪、人物质感和多视角都属于派生生成：源节点保持不变，结果写入新节点。支持蒙版的渠道会使用局部合成；渠道能力、积分和失败退款仍由服务端校验。

## CPU 抠图

图片节点的“抠图”会创建持久化 `image_process` 任务，由内部 rembg sidecar 执行，不从浏览器直接访问模型服务。

- 只接受 JPEG、PNG 和 WebP；输入与输出各不超过 30MB，动画图片不支持。
- EXIF 方向会先校正；源图超过 6400 万像素会拒绝，最长边超过 2048px 时等比缩小，小图不放大。
- 新任务固定输出透明 RGBA PNG。默认模型为 `silueta`，自定义设置可从五个白名单模型中选择，并调整 Alpha Matting、前景/背景阈值、细化范围和蒙版清理。
- 全站同一时间只执行一个 rembg 推理。PostgreSQL 使用持久 FIFO、租约和 advisory lock；文件 Provider 使用跨进程锁。
- 排队和运行任务都可以取消。运行中取消会等待 sidecar 子进程终止，迟到结果不会登记或写回画布。
- 完成结果保存为站内媒体并登记用户、画布、任务和来源关系；读取、下载和删除继续经过媒体归属与引用保护。

## 视频节点

- 工具栏可以新建视频节点，也可以拖入或上传本地视频文件。
- 视频节点使用原生播放器展示内容，可在节点内直接播放、暂停和拖动进度。
- 空视频节点下方对话框可输入提示词生成视频，结果会回填到当前节点。
- 从文本、图片或配置节点创建视频生成时，会在右侧生成新的视频节点并自动连接。
- 生成配置节点的视频模式会读取上游文本作为 prompt，读取上游图片作为参考图，读取上游视频作为参考视频，并在输入预览里显示参考视频。
- 视频生成接口支持 OpenAI 风格的 `POST /v1/videos`、`GET /v1/videos/{id}` 和 `GET /v1/videos/{id}/content`。
- 使用火山方舟 Agent Plan / Seedance 2.0 时，Base URL 配置为 `https://ark.cn-beijing.volces.com/api/plan/v3`，模型名使用 Seedance 2.0 对应模型；系统会改用 `POST /contents/generations/tasks` 创建异步任务，并轮询 `GET /contents/generations/tasks/{id}`。
- Agent Plan 专属 `/api/plan/v3` 当前未提供 OpenAI `/models` 模型列表接口，后台模型拉取不会伪造模型列表；请手动填写 `doubao-seedance-2.0` 或文档列出的其他可用模型。
- Seedance 等只接受可访问 URL 的渠道由服务器为站内素材生成短期签名地址；素材仍保存在本地服务器，前端不会直接向上游发送本地文件或长期公开存储地址。

## 推荐流程

1. 新建文本节点，写入图片创作想法。
2. 打开文本节点下方对话框，让 AI 优化或扩写这段提示词。
3. 改写结果会生成到新的文本节点，保留原始文本方便对比。
4. 确认文本节点内容后，点击顶部工具栏“生图”。
5. 在自动创建的生成配置节点中继续调整图片参数或重新生成。
6. 在右上任务面板核对真实阶段和结果；需要派生处理时从图片快捷工具继续操作，保留源节点作为可追溯输入。
