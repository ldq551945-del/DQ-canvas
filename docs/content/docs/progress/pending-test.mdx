- 后台系统设置新增生图/视频工作台 Agent 智能规划默认开关，并通过公开会话同步到前端；旧 PostgreSQL `generation_defaults` 会在读取时补齐默认开关。关闭后对应工作台会提示并打开图片或视频模型选择器，视频工作台默认定位视频分类，未选择模型时不会静默提交默认模型。本地登录态已验证桌面和 390px、浅色和深色主题、提交拦截及弹层无横向溢出。模型路由在所有渠道短时冷却时保留最高优先级重试候选，避免把已配置的默认模型误报为“未配置”；仍需在宝塔部署环境验证真实密钥失效、冷却和恢复后的完整提示链路。
