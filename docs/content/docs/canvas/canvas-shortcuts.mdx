# 画布快捷键

本文档与画布左下角键盘按钮打开的快捷键说明保持一致。

## 视图

- 拖动画布空白处：平移视图。
- `Space` + 拖动：临时平移视图。
- 鼠标中键 + 拖动：平移视图。
- 鼠标滚轮：缩放画布。
- 缩放滑杆：精确调整缩放。
- 重置视图按钮：回到默认缩放和居中位置。
- 双击画布空白处：打开添加组件菜单。

## 选择

- `Ctrl / Cmd` + 拖动：框选多个节点。
- `Shift / Ctrl / Cmd` + 点击节点：追加或取消选择节点。
- `Ctrl / Cmd` + `A`：全选画布节点。
- `Esc`：取消选择或连线，并关闭当前浮层。

## 编辑

- `Ctrl / Cmd` + `C`：复制选中节点。
- `Ctrl / Cmd` + `V`：粘贴节点。
- `Delete / Backspace`：删除选中的节点或连线。
- `Ctrl / Cmd` + `Z`：撤销。
- `Ctrl / Cmd` + `Shift` + `Z`：重做。
- `Ctrl / Cmd` + `Y`：重做。

## 图片和素材

- 拖入媒体文件：上传图片、视频或音频到画布。
- `Ctrl / Cmd` + `V`：根据剪贴板内容粘贴节点、文本或图片。
- 上传素材按钮：从本地选择媒体文件。
- 我的素材：选择素材后插入画布。

## 添加组件菜单

- `Arrow Up / Down / Left / Right`：在七类组件之间移动焦点。
- `Home / End`：跳到第一个或最后一个组件。
- `Enter / Space`：创建当前组件。
- `Esc`：关闭菜单并把焦点还给添加按钮。

## 撤销和重做范围

撤销和重做会记录画布节点、连线、视口、背景模式和助手会话变化。画布项目名称、账号状态、全局 AI 配置和“我的素材”保存操作不属于当前画布历史。
